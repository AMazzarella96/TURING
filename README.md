TURING - disTribUted collaboRative edItiNG

Project developed during 3rd year of Computer science bachelor's degree. The goal of the project was to develop a collaborative editing system for documents, using multithread and sockets to allow different users working on a same document to chat with eachother while working. 
Each document (represented in this project as a separate folder) is divided in different sections (represented in this project as separate files). Users can work on different documents at the same time, one section at a time. 
The system would prevent two different users from editing the same section of a document.
The system also comes with a GUI developed using Java Swing framework.
